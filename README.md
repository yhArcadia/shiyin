# 拾音

面向备课场景的视频音频分段工具。左侧预览视频，右侧整理片段；拖动松手后留下固定标记，播放确认后按原标记切分。视频与输出音频均在浏览器本地处理。

## 本地运行

需要 Node.js 20 或更新版本。

```sh
npm install
npm run build
npm run dev
```

打开终端打印的本地地址，默认是 http://127.0.0.1:4173/。Windows 的 PowerShell 如果限制 npm.ps1，可用 `npm.cmd` 替代 `npm`。

## 功能

- 本地视频预览；固定分段标记；回到标记；毫秒时间输入；时间轴缩放。
- 连续片段共享边界，支持拖动或键盘微调；点击切分点合并相邻片段；撤销与重做。
- 时间轴连续缩放与平滑动画；拖动刻度、片段区域平移视野；点击片段空白处勾选。
- 手动命名、前缀加编号、重名处理、中文文件名；勾选决定是否导出。
- 单段 MP3 / WAV 下载、多段 ZIP 打包；真实进度、取消、失败重试。
- 浏览器本地自动保存草稿，重新选择同名同大小的原视频可恢复。

导出采用单线程 ffmpeg.wasm，不要求 SharedArrayBuffer 或特殊隔离响应头。文件优先通过 WORKERFS 挂载读取。音频核心只在首次导出时加载，依赖全部随网站提供，不依赖外部 CDN。核心二进制按 1 MiB 分片，下载时实时显示 MB 进度；支持本机缓存、自动重连与超时退出，重试时复用已完成的分片。缓存不可用时仍可下载使用。

这一版适合电脑浏览器和 20 分钟以内、几百 MB 的课堂素材；单文件上限 1 GiB。预览格式取决于浏览器解码能力，推荐常见的 MP4 视频。浏览器处理较大素材时仍受设备内存和 CPU 限制。

草稿只保存片段时间、名称和文件基本信息，不保存视频本身。关闭页面后需要重新选择原视频。清除网站数据、换浏览器或换域名会影响草稿。MP3 编码可能包含短暂的编码填充；需要按采样点检查时长时可选择 WAV。

## 发布

GitHub Pages 的自动部署配置已放在 `.github/workflows/pages.yml`，首次配置与后续更新见 [DEPLOY.md](DEPLOY.md)。

`npm run build` 生成的 `dist/` 是完整的静态网站，可部署到 GitHub Pages 或其他静态托管服务。使用相对路径，支持 GitHub 项目站点的子路径；发布全部文件即可，不需要服务器端 FFmpeg。

本项目还包含 Sites 的静态托管配置 `.openai/hosting.json`。保留该文件中的站点身份，后续发布应复用同一站点。

## 检查

```sh
npm test
npm run build
```

依赖与许可证见网站的 `credits.html`。`test/fixtures/` 与 `test/results/` 是本地音视频验证目录，不会进入发布源代码。
